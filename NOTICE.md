# Driver Companion notice

## Third-party audio assets

None. This repository intentionally ships with an empty music catalog.

Do not add audio, lyrics, backing tracks, samples, stems, voice models, or music metadata to the repository unless it first meets the CC0-only intake policy in [`docs/OPEN_CONTENT_POLICY.md`](docs/OPEN_CONTENT_POLICY.md).

## Third-party software

The demo uses standard browser APIs only and currently bundles no third-party runtime package.

## Required update format for future CC0 audio

For every accepted asset, add a concise entry here with:

1. Asset title and immutable catalog ID.
2. Creator or dedicating rights holder.
3. Verifiable source URL and retrieval date.
4. `CC0-1.0` links for both the composition and sound recording.
5. Confirmation that it contains no lyrics or third-party samples unless each element has equivalent documented CC0 provenance.
