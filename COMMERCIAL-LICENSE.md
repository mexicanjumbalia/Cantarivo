# Commercial licensing

This repository's current source code is made available under the [PolyForm Noncommercial License 1.0.0](LICENSE). That license permits noncommercial uses and does not itself grant a commercial-use right.

Commercial rights, if ever offered, require a separate written agreement signed by every relevant rightsholder. No commercial license is created by a GitHub issue, a donation, a sponsorship, a pull request, a message, or silence.

The project does not currently publish a commercial licensing price, application form, or contact endpoint. If a commercial program is established, maintainers will publish its scope and a project-owned contact method. Do not post personal contact information in public issues.

This file is a project policy, not a legal opinion or a signed contract.
