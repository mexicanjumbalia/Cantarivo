Current status

Cantarivo now includes an optional local AI vocal cue prototype. It is a short, wordless, voice-shaped cue generated on the device after the user allows the companion for the current session. It does not include a human singer, voice clone, lyric generator, cloud audio service, or artist imitation.

Recommended first AI-vocal path

Keep the current on-device cue engine for the immediate preview, then build a small pack of original, rights-cleared, pre-rendered wordless AI vocal cues. The pack lives in the app, plays only after a person chooses it for the current session, never receives microphone audio, and is labelled as AI-generated. It is not a voice clone and must not imitate a recognizable performer.

This is a content-production and rights project before it is an in-app feature. Each cue needs documented source voice authorization, training-data/model rights, composition/master rights where applicable, performer consent, package checksum, and a stop/quiet control. The AI vocal roadmap is included in the repository review packet.

Cloud or voice-conversion option

Not approved for this project. A cloud AI singer or a system trained to sound like a person would change the privacy, rights, safety, and store-disclosure picture. It needs a named provider, a signed data-processing review, explicit user consent directly before activation, a revised Data Safety declaration, a revised privacy policy, and written authorization for every voice and musical asset. No such provider or voice model is integrated here.

Consent and rights boundary

The app must not activate companion output without an explicit session choice and must keep Silence / Stop and End session immediately accessible. The assistant must never claim to identify a person or song, or sing in a real person's voice without evidence and written authorization.
